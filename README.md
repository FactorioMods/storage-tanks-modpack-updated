# Storage Tank Modpack: Updated

Keeps the original optional storage-tank collection available on Factorio 2.1.24 or later.

Tank types and capacities are provided by the individual tank mods. Install the providers you want alongside this compatibility package; the original optional dependency list is retained.

Original project: [storage-tanks-modpack](https://mods.factorio.com/mod/storage-tanks-modpack) — Kuxynator. [Updated Mod Portal page](https://mods.factorio.com/mod/storage-tanks-modpack-updated) · [Fork source](https://github.com/FactorioMods/storage-tanks-modpack-updated).
